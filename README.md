# Banco de Dados 2
Este repositório objetiva armazenar todos os arquivos desenvolvidos na disciplina SIBD2303 - Banco de Dados 2, ministrada pelo Prof Neemias Cruz, ofertada pelo Departamento de Sistemas de Informação no Centro Federal de Educação Tecnológica Celso Suckow da Fonseca – Cefet/RJ Campus Maria da Graça, como disciplina obrigatória do Bacharelado em Sistemas de Informação.

# Proposta da disciplina
SQL (comandos essenciais e técnicas avançadas, processos de criação de views, procedures, functions, triggers e gestão de privilégios de usuários); estratégias de otimização, configurações de servidor, estratégias de backup; Monitoramento de bancos de dados; Processos de ETL; introdução a novos tipos de bancos de dados (orientados a documentos, grafos e colunar).

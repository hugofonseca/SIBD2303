# Banco de Dados 2
Este repositório objetiva armazenar todos os arquivos desenvolvidos na disciplina SIBD2303 - Banco de Dados 2, ministrada pelo Prof Neemias Cruz, ofertada pelo Departamento de Sistemas de Informação no Centro Federal de Educação Tecnológica Celso Suckow da Fonseca – Cefet/RJ Campus Maria da Graça, como disciplina obrigatória do Bacharelado em Sistemas de Informação.

# Ementa
- 1.Entrada de Dados com Python e PHP, Gerar arquivos tipo CSV, PDF e XLS.

- 2.Introdução ao Banco de Dados XBase. SQL (comandos essenciais e técnicas avançadas, processos de criação de views, procedures, functions, triggers e gestão de privilégios de usuários);

- 3.Estratégias de otimização, configurações de servidor, estratégias de backup;

- 4.Monitoramento de bancos de dados;

- 5.Processos de ETL;

- 6.Introdução a novos tipos de bancos de dados (orientados a documentos, grafos e colunar).

- 7.Tópicos Pedagógicos – Pensamento Computacional, Mente Criaativa, Filosofia da Educação.

# Objetivo Geral
Aprofundar os conceitos fundamentais do modelo relacional vistos no primeiro módulo, direcionando o foco para a arquitetura interna e o funcionamento dos Sistemas de Gerenciamento de Banco de Dados (SGBDs). Serão abordados tópicos avançados indispensáveis para um cientista da computação, incluindo o armazenamento físico de dados, estruturas de indexação primárias e secundárias, processamento e otimização de consultas algébricas, gerenciamento estrito de transações (propriedades ACID), protocolos de controle de concorrência, mecanismos de recuperação pós-falha, introdução aos bancos de dados distribuídos e o ecossistema moderno de armazenamento não-relacional (NoSQL/NewSQL).

# Competência desenvolvida:
Modelar Dados e Tratar com os os tipos mais comuns de SGDB, e desenvolver um banco de dados para aplicações diveersas.

# Conteúdo programático:
Aulas teóricas e práticas utilizando Python PHP e SGDB, utilizando Laragon como Servidor.

# Metodologia de ensino:
Aulas práticas e Teóricas utilizando material didático e práticas utilizando computadores, com aplicações típicas de Banco de Dados. Aprendendo sobre Tecnologia e Educação Técnica.
